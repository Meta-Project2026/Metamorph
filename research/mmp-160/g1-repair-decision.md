## Current boundary that must survive

`publicRepairDecision()` rejects G1 FAIL with `G1_FAILED` before checking full
comparison feedback. `meta-paid-migration.yml` calls `repair-gate` only when
`steps.validation.outcome == 'success'`; a real G1 failure makes validation
nonzero and leaves G2/G3 incomplete. The existing path correctly admits only a
complete public FAIL with successful G1 and full independent comparison evidence.
Flipping one boolean, treating the Oracle step as success, adding TS2769 to
generic `CODES`, or making incomplete G2/G3 look complete would violate that
contract. The old complete-comparison path must retain its existing checks.

## Proposed narrowly versioned eligibility

Use a distinct stage result and opaque trusted repair capability. Admit only:

1. The original reviewed `generate_then_repair` plan reserved two POSTs and one
   repair before send 1. Run attempt is 1; attempt 1 has one confirmed real
   response, a bound candidate and no existing attempt-2 claim/send ambiguity.
   A `single_generation` plan cannot be upgraded after failure.
2. Normal compiler failure in the first typecheck stage only: exactly one
   executed failing G1 test, no build/environment error or cancellation, and
   complete trusted `mmp082-g1-diagnostics-v1` diagnostics with status AVAILABLE,
   `errorCount=1`, `truncated=false`, exactly one allowlisted TS2769. Its path is
   a bounded canonical `src/**/*.ts` path present in the admitted bundle; line
   and column are positive bounded integers within that exact file.
3. The verifier binds run ID/attempt, exact reviewed head/workflow, public source,
   context, manifest, attempt ID, pair ID, candidate digest, stage and diagnostic
   digest. Validate trusted receipt origin, not merely a schema-valid JSON file.
   Stale, foreign, duplicate, missing, truncated, extra-error or mixed-stage data
   is NO_GO. No fallback from malformed G1 metadata to generic public repair.
4. Authenticated candidate stored/readback custody matches all those identities;
   the exact immutable model-generated bytes are available to the trusted host
   through the same-run lease. Normal and independent cleanup prove zero owned
   resources with no ambiguous active operation. Never decrypt historical private
   candidates or transfer keys into an agent environment to recover this state.
5. G2/G3 intentionally have zero observations at this stage and remain
   INCONCLUSIVE. G0/G4 and product remain unestablished. The new stage conveys
   `G1_BUILD_RECOVERABLE`, not Oracle success or complete public parity failure.

## Minimal implementation outline, only after joint approval

1. Owners agree a versioned early-stage result, trusted diagnostic provenance and
   exact declassification schema. Keep it separate from complete G2/G3 results.
2. The runner persists the actual nonzero Oracle result and explicit stage;
   credential-free routing may inspect that durable result after failure.
   Preserve the original failure in reports rather than masking the Oracle exit.
   Unrelated harness errors must stop without a second send.
3. A dedicated gate issues a single-use capability only after all eligibility
   and custody checks. The paid host independently revalidates it with fresh
   OIDC, current protected main/workflow, tariff/aggregate bounds and durable
   exclusive-create attempt-2 ledger. Existing SEND_UNKNOWN never permits retry.
4. Construct a versioned repair body containing the exact same model's previous
   generated changes and only approved public `{code,path,line,column}` data.
   Treat previous code as data. No raw stderr, detailed private compiler text,
   reference/held-out output, secrets, external source or candidate plaintext in
   public logs/PRs. Bind the exact serialized body in the second signed admission.
5. Send at most one second POST, with no retry/third send. Admit the returned
   candidate afresh, capture its own encrypted custody/readback and run fresh
   independent G1 then full G2/G3 in disposable isolation. A second G1 failure
   stops. Keep truthful partial coverage, billing UNKNOWN where appropriate,
   scorecard lineage and both normal/independent cleanup for each attempt.
